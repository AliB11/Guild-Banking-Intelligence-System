# منابع اطلاعاتی GBI

این سند همان قراردادی است که صفحهٔ «منابع و به‌روزرسانی» و جاب ماهانه از آن می‌خوانند.

## قاعده طلایی

| نوع | معنی | آیا رقم KPI را پر می‌کند؟ |
| --- | --- | --- |
| رسمی | شاپرک، بانک مرکزی، امور مالیاتی، مرکز آمار، اتاق اصناف | بله، فقط ارقام نقل‌شده با ذکر شماره گزارش |
| مدل | فرض خزانه‌داری / پلکان کارمزد داخل موتور | بله، به‌عنوان assumption با شماره نسخه |
| داخلی بانک | پایانه شعبه، رسوب CASA | در GitHub Pages نمایش داده نمی‌شود (صفحه حذف شده) |
| آینه خبری | EcoIran، banker.ir، راه پرداخت | فقط برای خواندن متن گزارش شاپرک وقتی PDF نرسد |

نام پذیرنده، کد ملی، جواز، مانده CASA، گردش رسته و قیف شعبه از منبع عمومی قابل اتکا نیست؛ **ساخته نمی‌شود** و صفحه متناظر از محصول حذف شده است.

## شکاف داده اصناف (سودآوری و ارزش رسته)

رتبه‌بندی سودآوری رسته‌ها از منبع عمومی **ممکن نیست** و در محصول ساخته نشده است.

| منبع | چه می‌دهد | چه نمی‌دهد |
| --- | --- | --- |
| ماهنامه شاپرک | جمع شبکه، ابزار (کارتخوان/اینترنت)، سهم بانک پذیرنده | جدول ماهانه گردش به تفکیک رسته جواز یا MCC |
| پلکان کارمزد بانک مرکزی | معافیت نانوایی و سوپرمارکت؛ پلکان عمومی کارتخوان | کارمزد اینترنت؛ سود بانک از رسته |
| جدول اینتا / تبصره ۱۰۰ | ضریب سود مالیاتی فقط جایی که نقل شده (سوپرمارکت ۸٫۵٪، رستوران ۱۴٪، اغذیه ۱۵٪ کف) | حاشیه بانک؛ جدول کامل همه رسته‌ها در این نسخه |
| اتاق اصناف / صمت | شمار واحد در نقل‌های متناقض (حدود ۲٫۴ میلیون فعال بهمن ۱۴۰۰ صمت؛ حدود ۳٫۵ میلیون مجوزدار نقل ۱۴۰۵ اتاق) | موجودی جاری قابل اتکا برای KPI؛ گردش شاپرک رسته |
| مرکز آمار | طرح‌های قدیمی کارگاه عمده/خرده | ترکیب ۱۴۰۵ شاپرک |

تا وقتی شاپرک جدول MCC را علنی کند یا هسته بانک گردش پایانه و CASA بدهد، اطلس فقط **طبقه‌بندی سیاست** دارد: معاف کارمزد / اینتا نقل‌شده / فقط کد.

## دوره جاری

تقویم ممکن است شهریور ۱۴۰۵ باشد؛ آخرین ماهنامه شاپرک در این نسخه **مرداد ۱۴۰۵ / گزارش ۱۳۴** است. شهریور به‌عنوان KPI نمایش داده نمی‌شود.

سری نقل‌شده:

| ماه | تعداد | مبلغ | منبع |
| --- | --- | --- | --- |
| خرداد ۱۴۰۵ | ۴٫۶۸۸ میلیارد | ۳۳۶۷ همت | banker.ir، گزارش ۱۳۲ |
| تیر ۱۴۰۵ | ۴٫۵۱۶ میلیارد | ۳۴۰۶ همت | بازتاب + سازگاری MoM مرداد |
| مرداد ۱۴۰۵ | ۴٫۶۵ میلیارد | ۳۶۵۴ همت | EcoIran، گزارش ۱۳۴ |

کارتخوان مرداد: حدود ۴ میلیارد تراکنش / ۲۷۷۶ همت؛ اینترنت ۲۷۳ میلیون / ۸۶۰ همت. سبد کارتخوان حدود ۶۹۴ هزار تومان.

## منابع

1. **گزارش اقتصادی ماهانه شاپرک** — [shaparak.ir](https://www.shaparak.ir) — حدود ۱۲ روز پس از پایان ماه جلالی.
2. **اصطلاحات پذیرنده شاپرک** — [shaparak.ir/docs/terms](https://www.shaparak.ir/docs/terms).
3. **کد MCC** — نگاشت رسته به شبکه پرداخت.
4. **پلکان کارمزد خرید کارتی** — بانک مرکزی؛ در مدل: زیر ۶ میلیون ریال ۱٬۲۰۰ ریال، بالاتر ۰٫۰۲٪ تا سقف ۴۰٬۰۰۰ ریال. نانوایی و سوپرمارکت معاف‌اند.
5. **نرخ تسهیلات و سپرده قانونی** — فرض مدل ۲۳٪ و ۱۳٪ (فقط وقتی CASA موجود باشد).
6. **اینتاکد و تبصره ماده ۱۰۰** — فقط ضرایب نقل‌شده: سوپرمارکت ۸٫۵٪ (۲۲۶۰۱۳۳)، رستوران معمولی ۱۴٪، اغذیه ۱۵–۲۰٪.
7. **ISIC** — مرکز آمار ایران.
8. **رسته‌بندی اتاق اصناف ایران**.
9. **سامانه مؤدیان** — استعلام اتصال؛ از GitHub واکشی نمی‌شود.
10. **پایش ماهانه پایانه بانک** — منبع داخلی.
11. **مانده CASA** — منبع داخلی؛ در حالت استاتیک غایب.
12. **آینه خبری شاپرک** — خواندن متن گزارش وقتی PDF در دسترس نیست.

## جاب ماهانه

Workflow `.github/workflows/monthly-refresh.yml` روزهای ۳، ۸، ۱۲، ۱۸ و ۲۵ هر ماه میلادی (۰۵:۳۰ UTC) صفحهٔ هر منبع را واکشی می‌کند، اثرانگشت را ذخیره می‌کند و اگر پنجره جلالی یا هش عوض شده باشد کاتالوگ را در `public/data/intelligence-catalog.json` commit می‌کند.

- ارقام اینتاکد/کارمزد **خودکار جایگزین نمی‌شوند**؛ فقط پرچم بازبینی انسانی می‌خورد.
- اگر سایت‌های ایران از رانر GitHub در دسترس نباشند جاب **شکست نمی‌خورد**؛ وضعیت `unreachable` ثبت می‌شود و corpus نقل‌شده باقی می‌ماند.

اجرای دستی:

```bash
npm run catalog:refresh          # با شبکه
npm run catalog:check            # بدون شبکه، فقط صحت شکل کاتالوگ
```
