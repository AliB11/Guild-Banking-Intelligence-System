# منابع اطلاعاتی GBI

این سند همان قراردادی است که صفحهٔ «منابع و به‌روزرسانی» و جاب ماهانه از آن می‌خوانند.

## قاعده طلایی

| نوع | معنی | آیا رقم KPI را پر می‌کند؟ |
| --- | --- | --- |
| رسمی | شاپرک، بانک مرکزی، امور مالیاتی، مرکز آمار، اتاق اصناف | فقط پس از بازبینی انسانی یا نگاشت نسخه‌بندی‌شده |
| مدل | فرض خزانه‌داری / پلکان کارمزد داخل موتور | بله، به‌عنوان assumption با شماره نسخه |
| داخلی بانک | پایانه، رسوب CASA، قیف شعبه | در GitHub Pages خیر (نمونه)؛ در PostgreSQL بله |
| نمونه | corpus دترمینیستیک شش‌ماهه جلالی | بله، با برچسب «داده نمونه» |
| آینه خبری | راه پرداخت و مشابه | خیر — فقط زنگ «گزارش منتشر شد» |

## منابع

1. **گزارش اقتصادی ماهانه شاپرک** — [shaparak.ir](https://www.shaparak.ir) — حدود ۱۲ روز پس از پایان ماه جلالی.
2. **اصطلاحات پذیرنده شاپرک** — [shaparak.ir/docs/terms](https://www.shaparak.ir/docs/terms).
3. **کد MCC** — نگاشت رسته به شبکه پرداخت.
4. **پلکان کارمزد خرید کارتی** — بانک مرکزی؛ در مدل: زیر ۶ میلیون ریال ۱٬۲۰۰ ریال، بالاتر ۰٫۰۲٪ تا سقف ۴۰٬۰۰۰ ریال.
5. **نرخ تسهیلات و سپرده قانونی** — فرض مدل ۲۳٪ و ۱۳٪.
6. **اینتاکد و تبصره ماده ۱۰۰** — سازمان امور مالیاتی؛ معمولاً سالانه.
7. **ISIC** — مرکز آمار ایران.
8. **رسته‌بندی اتاق اصناف ایران**.
9. **سامانه مؤدیان** — استعلام اتصال؛ از GitHub واکشی نمی‌شود.
10. **پایش ماهانه پایانه بانک** — منبع داخلی.
11. **مانده CASA** — منبع داخلی.
12. **آینه خبری شاپرک** — فقط کشف انتشار.

## جاب ماهانه

Workflow `.github/workflows/monthly-refresh.yml` روزهای ۳، ۸، ۱۲، ۱۸ و ۲۵ هر ماه میلادی (۰۵:۳۰ UTC) صفحهٔ هر منبع را واکشی می‌کند، اثرانگشت را ذخیره می‌کند و اگر پنجره جلالی یا هش عوض شده باشد کاتالوگ را در `public/data/intelligence-catalog.json` commit می‌کند.

- ارقام اینتاکد/کارمزد **خودکار جایگزین نمی‌شوند**؛ فقط پرچم بازبینی انسانی می‌خورد.
- اگر سایت‌های ایران از رانر GitHub در دسترس نباشند جاب **شکست نمی‌خورد**؛ وضعیت `unreachable` ثبت می‌شود.
- ماهنامه هوش اصناف همیشه از corpus جاری (نمونه یا PostgreSQL در پروفایل full-stack) بازتولید می‌شود.

اجرای دستی:

```bash
npm run catalog:refresh          # با شبکه
npm run catalog:check            # بدون شبکه، فقط صحت شکل کاتالوگ
```
